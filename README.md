# kotlin-blackjack

- 트럼프 카드
  - 문양과 숫자를 가진다
- 문양
  - 클로버,하트,다이아,스페이드를 가진다
- 숫자
  - A,2~10 J,Q,K 을 가진다
- 카드들
    - 카드들 상태
    - 블랙잭: 카드가 2장이고 21일 경우
    - 스테이: 21 이하일 경우
    - 버스트: 21 초과
    - 승패 조건
        - 블랙잭
            - 스테이와 버스트를 이긴다
            - 블랙잭일 경우에 비긴다
        - 스테이는
            - 블랙잭에게 지고 버스트에게 이긴다
            - 둘다 스테이일 경우에 높은 점수가 이긴다.
            - 둘다 스테이일 경우에 같은 점수일 경우 비긴다.
        - 버스트
            - 먼저 버스트된 사람이 패배한다
- 승부
  - 각 플레이어들의 승패를 반환한다
- 딜러
  - 카드가 17 이상인지 여부를 반환한다.
  - 카드를 받는다.
  - 카드들의 정보를 반환한다.
- 플레이어
  - 카드가 21 이상인지 여부를 반환한다.
  - 카드를 받는다.
  - 카드들의 정보를 반환한다.
- 협력
  - 덱을 통해서 딜러나 플레이어에게 카드를 2장씩 나눈다
  - 플레이어는 21 이하일 경우 카드를 더 받을지 말지 선택한다
  - 딜러는 17점 이상이 될때까지 카드를 받는다
  - 각 플레이어들의 승패를 반환한다.
  - 딜러의 각 플레이어와의 승패를 반환한다.
